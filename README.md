# 自分で姿かたち変えるアプリシリーズ

2つの独立したPWAプロトタイプを、それぞれのフォルダに分けています。

## アプリ

- `目覚ましアプリ/`: めざまし変形
- `家計簿/`: かけいぼ変形

## 変形の考え方

- まずはLLMではなく、機能のON/OFFで表示を変える
- 編集ボタンを押すと編集モードになり、パネルを長押しして移動できる
- 変形パネルに広告枠を置き、将来の収益化ポイントにする
- 変更内容はブラウザのローカルストレージへ保存する

## 注意

目覚ましはブラウザを開いている間だけ鳴ります。iOS本番化ではCapacitorやSwiftネイティブ通知に置き換える想定です。
